# FlashDock changelog

See [GitHub Releases](https://github.com/klein-sys/own-flasher/releases) for published downloads and release notes.

## v1.7.3

- Keep install readiness and **Arm Write** visible while scrolling through package options.
- Review the target device, selected package, incoming and installed versions, and enabled options before installing.
- Leave automatic runtime permission grants and version downgrades off by default.
- Show actionable package and install errors with a **Copy Details** button.

## v1.7.2

- Validate packages in the background and block installation when an archive contains unreadable entries.
- Preserve the selected APK during validation.

## v1.7.1

- Allow drag-and-drop and file browsing for packages and recovery ZIPs while Write is Safe.
- Require Write to be armed and the device to be in the appropriate ADB mode before installing.

## v1.7.0

- Group 16 tools into four workflow sheets with Pearl Light and Obsidian Dark themes.
- Show connection status and reported device telemetry in the top bar. Return Write to Safe when the device or connection mode changes.
- Add a Windows launcher for running from source.
